# Инструкция для нового чата — product_features

Скопировать в новую беседу ChatGPT Project вместе с архивом/CSV предыдущего чата:

> Продолжаем задачу по Strapi Product → `product_features` для 2584 товаров категории «Макияж» (`locale=ru`).
>
> **Сначала прочитай актуальный handoff:** https://github.com/mbtema/strapi/blob/main/project/product-features-handoff.md и при необходимости https://github.com/mbtema/strapi/blob/main/project/context.md. Активные Project Instructions важнее `project/instruction.md` (последний — staging). Используй приложенный `product-features-analysis-v3.csv` (или архив с исходным dataset, v3, review, summary). Данные локального старого чата не считаются автоматически доступными новому.
>
> Последнее требование: **глубоко провести анализ всех 2584 товаров**, итоговые статусы на уровне Product **строго только `assigned`, `not_applicable`, `review`**. Никаких `[]`, `no_confirmed_claim` как финального состояния. `assigned` — один/несколько доказанных кодов, `not_applicable` — объективная неприменимость с причиной, иначе `review`. У назначенных товаров дополнительные сомнения по отдельным признакам сохраняй как `partial_review`, не отменяя уверенных присвоений. Категорией туши значения не ограничены (например, эффект объёма у губ).
>
> Последний v3 — **только промежуточный**, 751 assigned, 79 review-only, 1692 `[]`, 62 preliminary not-applicable; 1039 возможных связей, но **в Strapi ещё ничего не записывали**. Цифра 90,48% от «830 выявленных кандидатов» не является доказанной полнотой применимого каталога.
>
> **Сейчас выполни самостоятельно полный новый 3-state аудит** — источники из Product, затем официальный web по неоднозначным позициям. Не делай вывод «неприменимо» только потому, что нет claim; не придумывай косметические свойства. Выдай проверенный CSV на все 2584 записи, отдельные assigned/review файлы, источники/обоснования, breakdown по категориям и честное покрытие `assigned / (assigned + review)` при обоснованных исключениях. Глубокий анализ 1692 старых `[]` обязателен.
>
> **Массовую запись пока не запускай.** Старый `product-features-mass-assign.js` рассчитан на v3 и не должен выполняться до финального аудита/нового preflight. После вывода результатов согласуем запись отдельно. Не задавай заново вопросов о scope: всё указано в handoff.

Для минимального прикрепления достаточно **`product-features-analysis-v3.csv`**, потому что он включает 2584 строки исходного Product-контекста и предыдущие решения. Лучше приложить полный архив: `product-features-analysis-context.csv`, `product-features-analysis-v3.csv`, `product-features-review-v3.csv`, `product-features-summary-v3.csv`, дополнительные анализы и scope-файл.
