# PLAIN_TEXT / HTML / IMAGE
PLAIN_TEXT: только перевод, сохраняя абзацы, списки, переносы и техфрагменты.
HTML: переводи только русские text nodes и русский текст в alt/title/placeholder/aria-label. Не меняй теги, вложенность, порядок, whitespace, entities, комментарии, class/id/style/href/src/data-*, URL, CSS/JS, пути, <script>/<style>/<code>/<pre>. Не исправляй HTML. Результат — сырой HTML.
IMAGE: меняй только отдельно размещённый русский рекламный текст. Не трогай бренды/логотипы/упаковку и текст на ней, фото/людей/продукты, фон, композицию, цвета, размеры холста. Казахский текст ставь на место исходного, максимально сохраняя стиль/иерархию/выравнивание/размер; при нехватке места минимально адаптируй переносы/интервалы/размер. Нечитаемое не выдумывай. Результат — только изображение.
